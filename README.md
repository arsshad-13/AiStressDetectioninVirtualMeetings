This project detects real-time stress levels using facial expressions, voice tone, and typing behavior during virtual meetings.

## 🚀 Features
- Real-time monitoring with alerts
- Facial & voice simulation (or integrate real models)
- Typing pattern analysis
- Visualization and CSV export of stress logs

## 🛠 Setup
```bash
pip install -r requirements.txt
python app.py
```

## 📈 Output
- Real-time stress logs in terminal
- Alert notification during high stress
- Visual trend plotting
- Export to `stress_report.csv`
